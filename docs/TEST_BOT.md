# Как проверить Telegram-бота на своём Mac (с тестовым ботом)

Инструкция для человека без опыта программирования. Мы проверяем **основного бота** (меню для
волонтёра, клиента, куратора и админа) на копии сайта, которая работает на вашем Mac.

**Главное правило: настоящего бота не трогаем.** Его токен есть только на сервере
khayrkhoh.tj. Для проверки мы создаём **второго, тестового** бота — это бесплатно и занимает
две минуты. Тестовый бот видит только демо-данные с вашего Mac, настоящие клиенты о нём не знают.

Если что-то пошло не так, скопируйте последние 20–30 строк из Терминала и пришлите мне.

---

## Шаг 1. Создать тестового бота (один раз)

Нужен телефон или компьютер с Telegram — тот аккаунт, с которого вы будете проверять.

1. В поиске Telegram найдите **@BotFather** (с синей галочкой) и откройте чат с ним.
2. Отправьте ему: `/newbot`
3. Он спросит **имя бота** (видно в списке чатов). Напишите, например: `KhayrKhoh ТЕСТ`
4. Он спросит **username** — короткое имя, которое должно заканчиваться на `bot` и быть
   свободным. Например: `khayrkhoh_test_yusuf_bot`. Если занято, BotFather попросит другое —
   добавьте цифру: `khayrkhoh_test_yusuf2_bot`.
5. BotFather пришлёт сообщение со строкой **токена** — она выглядит примерно так:
   `7123456789:AAH4k-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Это пароль тестового бота. **Никому его не пересылайте и не вставляйте в чат со мной.**

Запишите себе два значения:
- **токен** тестового бота (строка из пункта 5);
- **username** тестового бота **без** `@` (из пункта 4), например `khayrkhoh_test_yusuf_bot`.

> Как не перепутать с настоящим ботом: у тестового бота username, который вы только что
> придумали (с `test`). Токен настоящего бота у вас на Mac больше не хранится — он только на сервере.

## Шаг 2. Вписать токен в файл настроек на Mac

1. Откройте **Терминал** (⌘ + Пробел → `Терминал` → Enter).
2. Вставьте и нажмите Enter:

   ```bash
   cd ~/Desktop/volunteers
   open -e .env
   ```

   Файл `.env` откроется в программе **TextEdit**.

3. Найдите строку `TELEGRAM_BOT_TOKEN=` и допишите **сразу после знака `=`** токен тестового
   бота — без пробелов и без кавычек:

   ```
   TELEGRAM_BOT_TOKEN=7123456789:AAH4k-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

4. Найдите строку `TELEGRAM_BOT_USERNAME=` и замените то, что после `=`, на username тестового
   бота **без `@`**:

   ```
   TELEGRAM_BOT_USERNAME=khayrkhoh_test_yusuf_bot
   ```

   Это нужно, чтобы кнопка «Открыть в Telegram» на сайте вела в тестового бота, а не в настоящего.

5. Больше ничего в файле не меняйте. Сохраните: **⌘ + S**, закройте TextEdit.

Строки `SMTP_…` должны остаться **пустыми** — письма на Mac только печатаются в Терминал.

## Шаг 3. Запустить сайт и бота (два окна Терминала)

Сайт и бот — это две отдельные программы, поэтому нужно **два окна** Терминала.

**Окно 1 — сайт.** Вставьте по очереди:

```bash
cd ~/Desktop/volunteers
source .venv/bin/activate
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Вверху появится рамка из восклицательных знаков `WARNING / ВНИМАНИЕ … TELEGRAM_BOT_TOKEN`.
**Для тестового бота это нормально** — это напоминание, что в `.env` вписан токен. В конце
должно быть `Starting development server at http://127.0.0.1:8000/`. Окно не закрывайте.

**Окно 2 — бот.** Откройте новое окно Терминала (⌘ + N) и вставьте:

```bash
cd ~/Desktop/volunteers
source .venv/bin/activate
python manage.py run_telegram_bot
```

Должно появиться `Telegram bot started`. Это окно тоже не закрывайте — пока оно открыто, бот
отвечает. Если вместо этого `TELEGRAM_BOT_TOKEN не задан в .env` — вернитесь к шагу 2 (токен не
сохранился).

Откройте в браузере **http://127.0.0.1:8000/** — пароль всех демо-аккаунтов `Volunteer2026!`.

## Шаг 4. Как привязать Telegram к роли

Один аккаунт Telegram привязывается **к одному** аккаунту сайта. Поэтому проверяем по очереди:
привязали роль → проверили → отвязали → привязали следующую.

**Привязать:**
1. Войдите на сайте под нужным демо-аккаунтом (таблица ниже).
2. **Профиль** → кнопка **«Привязать Telegram»** → **«Сгенерировать код привязки»**.
3. Нажмите **«Открыть в Telegram»** → откроется тестовый бот → нажмите **Start** (или
   «Запустить»). Бот ответит `Готово! Telegram привязан к аккаунту …` и покажет меню роли.

   Если кнопка не открывает Telegram: скопируйте строку `/link …` со страницы и отправьте её
   тестовому боту обычным сообщением.

**Отвязать** (перед сменой роли): на сайте под **той же** ролью → **Профиль** → **«Привязать
Telegram»** → **«Отвязать Telegram»**. Затем выйдите с сайта и войдите под следующей ролью.

Если бот пишет «Этот Telegram уже привязан к другому аккаунту» — вы забыли отвязать прошлую роль.

| Роль | Логин | Область |
|---|---|---|
| Клиент | `client_zamira` | Душанбе |
| Волонтёр (без текущей задачи) | `madina_b` | Душанбе |
| Волонтёр (уже с задачей) | `malika_s` | Согд |
| Куратор | `curator_samira` | Душанбе |
| Админ | `admin_demo` | — |

Удобно: Telegram — на телефоне (за проверяемую роль), а «вторую сторону» (например, волонтёра,
который принимает запрос клиента) делать в браузере на компьютере.

## Шаг 5. Сценарий проверки по ролям

Отмечайте галочкой то, что сработало. Всё, что не сработало, — запишите (что нажали и что
увидели) и пришлите мне.

### 5.1. Клиент (`client_zamira`)

- [ ] После привязки бот показывает меню клиента: «➕ Новый запрос», «📋 Мои запросы», …
- [ ] «➕ Новый запрос» → выбрать вид помощи кнопкой → написать описание → **отправить
      геопозицию** (скрепка → Геопозиция) или написать адрес текстом → нажать **«Отправить мой
      номер»** → выбрать срочность → бот показывает «Проверьте запрос:» → «Отправить».
- [ ] Напишите номер с ошибкой (например, `12345`) вместо кнопки — бот вежливо просит ещё раз и
      не «падает».
- [ ] На сайте в браузере войдите как `curator_samira` — новый запрос виден в списке задач.
- [ ] **Вторая сторона в браузере:** выйдите и войдите как `madina_b` → откройте этот запрос →
      «Принять». В Telegram клиенту приходит сообщение «Запрос принят…».
- [ ] Там же, как `madina_b`, напишите в чат запроса «Здравствуйте, я в пути». В Telegram
      приходит уведомление с командой вида `/chat_123` → нажмите её → напишите ответ → на сайте
      ответ появляется в чате.
- [ ] Как `madina_b` завершите запрос на сайте. В Telegram клиенту приходит просьба оценить →
      «📋 Мои запросы» → запрос → «⭐ Оценить помощь» → поставить звёзды.
- [ ] «📋 Мои запросы» → другой запрос в ожидании → «Отменить запрос» → «Да» → «Запрос отменён.»

### 5.2. Волонтёр (`madina_b`)

Сначала отвяжите клиента (шаг 4), привяжите `madina_b`. Как клиент `client_zamira` (в браузере
или через бота, если вы привязали его вторым аккаунтом) создайте ещё один запрос в Душанбе.

- [ ] Меню волонтёра: «🔎 Запросы рядом», «📌 Моя задача», «🏅 Значки и оценка», …
- [ ] «🔎 Запросы рядом» → запрос → в карточке **есть адрес, но нет телефона** клиента.
- [ ] «✅ Принять запрос» → теперь в «📌 Моя задача» **телефон виден**.
- [ ] Быстро нажмите «✅ Принять» два раза подряд — запрос принимается один раз, без ошибки.
- [ ] «🚶 Я в пути» → «📍 Я на месте» → «🤝 Начал помогать»: этапы меняются; на сайте в карточке
      запроса меняется шаг.
- [ ] «🗺 Маршрут» → кнопки навигаторов открываются.
- [ ] Отправьте боту **трансляцию геопозиции** (скрепка → Геопозиция → «Транслировать») — на
      сайте как `curator_samira` на карте виден маркер волонтёра. Потом остановите трансляцию.
- [ ] «💬 Чат» → напишите сообщение и отправьте фото → на сайте у клиента оно появилось.
- [ ] «Опасность / SOS» → «Отправить SOS» → «Сигнал отправлен…». Повторное нажатие — «У вас уже
      есть открытый сигнал…» (второй сигнал не создаётся).
- [ ] «🏁 Завершить» → подтвердить → «Запрос завершён. Спасибо за помощь!»

### 5.3. Куратор (`curator_samira`)

- [ ] Меню координатора: «⏱ Просроченные», «⌛ Долго ждут», «🙋 Без волонтёра», «🆘 Сигналы SOS»,
      «📦 Пожертвования», «📣 Рассылка волонтёрам».
- [ ] «🙋 Без волонтёра» → запрос → **телефон клиента виден** (куратор видит всегда) →
      «Подобрать волонтёра» → список из 3 лучших → назначить одного. Если у волонтёра включено
      «не беспокоить», бот переспрашивает — ответ «Да» назначает.
- [ ] «🆘 Сигналы SOS» → сигнал из шага 5.2 → «Принять сигнал» → «Решено».
- [ ] «📣 Рассылка волонтёрам» → короткий текст → отправить. (Придёт только тем демо-волонтёрам,
      у кого привязан Telegram, — то есть, скорее всего, никому. Это нормально.)

### 5.4. Админ (`admin_demo`)

- [ ] Меню как у куратора плюс «📝 Заявки» (заявки в волонтёры).
- [ ] «📝 Заявки» → заявка → одобрить или отклонить.

### 5.5. Общее (под любой ролью)

- [ ] `/lang` или «🌐 Язык» → переключить на Тоҷикӣ и English → меню на выбранном языке
      (таджикские тексты — заметьте, что звучит неестественно).
- [ ] `/menu` в любой момент возвращает меню; `/cancel` прерывает мастер нового запроса.
- [ ] На сайте **Профиль → «Привязать Telegram» → «Отвязать Telegram»** — бот после этого на
      `/start` предлагает привязать аккаунт заново.

**Кнопка «🌍 Открыть сайт» в боте ведёт на настоящий khayrkhoh.tj**, а не на ваш Mac (Telegram не
разрешает ссылки на `127.0.0.1`). При проверке её можно не нажимать.

## Шаг 6. Закончить проверку

1. В окне бота нажмите **Control + C** — бот остановится. В окне сайта — тоже **Control + C**.
2. Токен тестового бота можно оставить в `.env` (он безопасен — это не настоящий бот), но тогда
   рамка `WARNING / ВНИМАНИЕ` будет появляться при каждом запуске. Чтобы убрать: `open -e .env`,
   сотрите всё после `=` в строке `TELEGRAM_BOT_TOKEN=`, сохраните (⌘ + S).
3. Тестового бота удалять не обязательно — пригодится для следующих проверок. Если захотите:
   @BotFather → `/deletebot` → выбрать **тестового** бота (проверьте username!).

## Частые проблемы

| Что видите | Что делать |
|---|---|
| Бот не отвечает совсем | Окно 2 закрыто или там ошибка — запустите `python manage.py run_telegram_bot` снова |
| В окне бота `Unauthorized` или `InvalidToken` | токен вписан с ошибкой (пробел, кавычки, не целиком) — повторите шаг 2 |
| В окне бота `Conflict: terminated by other getUpdates request` | бот запущен в двух окнах — закройте лишнее окно (Control + C) |
| «Открыть в Telegram» открывает не тот бот | в `.env` в `TELEGRAM_BOT_USERNAME` не username тестового бота — шаг 2, пункт 4 |
| «Неверный или просроченный код» | код живёт 10 минут и срабатывает один раз — сгенерируйте новый на сайте |
| «Слишком много попыток привязки» | подождите 15 минут или перезапустите бота (Control + C и снова команду) |
| Уведомления в Telegram не приходят | проверьте, что Telegram привязан именно к той роли, которой адресовано событие |
