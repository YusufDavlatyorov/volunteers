# Бот сообщества волонтёров — настройка (для владельца)

Второй бот KhayrKhoh управляет Telegram-группой волонтёров и координаторов:

- впускает **только** одобренных волонтёров и координаторов с привязанным Telegram — по личной
  одноразовой ссылке на 24 часа. Ссылку выдают сайт (Профиль → «Сообщество волонтёров») или
  основной бот (кнопка «Сообщество волонтёров»);
- удаляет всех, кто вошёл иначе, а также тех, кто перестал быть волонтёром: заявку отклонили,
  аккаунт отключён, Telegram отвязан;
- модерирует: ссылки от участников удаляются, за флуд — пауза на 10 минут, `/report` — жалоба
  координаторам. Координаторы отвечают на сообщение командами `/warn`, `/mute [мин]`, `/ban`,
  `/mentor` (значок «Наставник»);
- закрепляет рассылки и новые акции с сайта, а раз в неделю публикует «Спасибо недели»: общие
  цифры и новые значки, **без рейтингов**. Волонтёр может отказаться от упоминания в профиле;
- **никогда не публикует данные клиентов.**

Без этой настройки всё остальное работает как обычно: бот сообщества просто не запускается.

## 1. Создать бота (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя, например: `KhayrKhoh Сообщество`. Username, например: `KhayrKhohCommunityBot`.
3. Скопируйте токен вида `123456789:AA…` — это секрет, никому его не пересылайте.
4. Там же выполните `/setjoingroups` → выберите бота → **Enable**, затем `/setprivacy` → бот →
   **Disable**. Без второго шага бот не видит обычные сообщения и не сможет модерировать.

## 2. Создать группу

1. Создайте группу, например «Волонтёры KhayrKhoh». Нужна **супергруппа**: Telegram обычно
   переводит группу в неё сам, когда вы назначаете администратора с расширенными правами (пункт 3 ниже).
   Проверка — id группы (раздел 3) начинается с `-100`. Если нет, включите в настройках группы
   «История чата для новых участников» → «Видна».
2. **Тип группы — частная** (без публичной ссылки): входить можно только по приглашениям бота.
3. Добавьте бота в группу и сделайте его **администратором** с правами:
   - удалять сообщения;
   - блокировать пользователей;
   - приглашать пользователей по ссылке;
   - закреплять сообщения.
4. Добавьте координаторов. Им приглашение не нужно, но их Telegram должен быть привязан на сайте.
5. Отдельные группы по регионам — по желанию, так же; бот добавляется в каждую.

**Важно:** если в группе уже есть люди, бот их не знает. Лучше начать с новой пустой группы, а
волонтёры войдут по своим ссылкам.

## 3. Узнать id группы

Напишите в группе `/id` — бот ответит, например, `chat id: -1001234567890`. Сохраните число
вместе с минусом.

## 4. Заполнить `.env` на сервере

```
TELEGRAM_COMMUNITY_BOT_TOKEN=123456789:AA…
TELEGRAM_COMMUNITY_BOT_USERNAME=KhayrKhohCommunityBot
# общий чат; региональные — через запятую, код региона: dushanbe, sogd, khatlon, gbao, rrp
TELEGRAM_COMMUNITY_CHAT_IDS=general:-1001234567890,sogd:-1009876543210
COMMUNITY_INVITE_HOURS=24
```

После правки `.env` перезапустите сайт и запустите бота:

```bash
cd /opt/khayrkhoh
sudo systemctl restart khayrkhoh-web khayrkhoh-celery khayrkhoh-telegram-bot   # чтобы сайт увидел новые переменные
sudo systemctl enable --now khayrkhoh-community-bot
journalctl -u khayrkhoh-community-bot -n 20 --no-pager           # "Community bot started (2 chat(s))"
```

Две cron-задачи — `community_sweep` раз в час и `community_weekly` по понедельникам — уже есть в
`deploy/crontab.example`; до настройки сообщества они только пишут «community not configured».

## 5. Проверить (вдвоём, 5 минут)

1. Волонтёр с привязанным Telegram: Профиль → «Сообщество волонтёров» → «Получить приглашение» →
   ссылка открывается в Telegram → он в группе, бот приветствует его по имени.
2. Та же ссылка у другого человека → бот сразу удаляет его из группы.
3. Участник отправляет ссылку на сторонний сайт → сообщение удалено.
4. Координатор отвечает на сообщение командой `/mentor` → у волонтёра на сайте появился значок
   «Наставник».
5. `.venv/bin/python manage.py community_weekly --preview` (в `/opt/khayrkhoh`) показывает текст
   «Спасибо недели», но ничего не публикует.

## Если что-то не так

| Признак | Причина |
|---|---|
| Бот не видит сообщения | не выключен privacy mode (`/setprivacy` → Disable), либо бот не администратор |
| «Не удалось создать приглашение» | у бота нет права «приглашать по ссылке», либо неверный chat id |
| Бот не удаляет чужих | у бота нет права «блокировать пользователей» |
| Кнопки «Сообщество» на сайте нет | не заданы токен или `general:` в `TELEGRAM_COMMUNITY_CHAT_IDS`, либо у пользователя нет привязанного Telegram |

Отключить бота: `sudo systemctl disable --now khayrkhoh-community-bot`. Сайт и основной бот
продолжат работать, ссылки на сайте перестанут выдаваться, как только переменные будут удалены
из `.env`.
